# Краткое описание реализованной системы:
В проекте я реализовал простую систему поведения NPC с использованием конечного автомата состояний. В сцене присутствует игрок и два типа противников: обычный противник и противник с возможностью телепортации

## PlayerMovement.cs
Скрипт отвечает за управление игроком
Игрок перемещается с помощью клавиатуры в восьми направлениях. Для движения используется CharacterController, который также отвечает за перемещение персонажа по сцене с учётом гравитации.
Игрок имеет тег Player, благодаря которому NPC могут автоматически найти его в сцене.

## NormalEnemyAI.cs
Скрипт управляет поведением обычного противника с помощью конечного автомата состояний
NPC имеет следующие состояния:

* Idle - ожидание;
* Patrol - патрулирование;
* Chase - преследование игрока;
* Attack - атака;
* Search - поиск игрока после его потери.

Для обнаружения игрока используется поле зрения 180°. Проверяется расстояние до игрока, угол обзора и наличие препятствия между NPC и игроком. Для проверки препятствий используется Physics.Raycast
Если игрок обнаружен, NPC переходит из Patrol или Idle в Chase. При приближении к игроку происходит переход в Attack. Если игрок теряется из поля зрения, противник переходит в Search, идёт к последней известной позиции игрока и некоторое время ищет его. После этого возвращается к патрулированию.
Атака имеет заданную дистанцию, задержку между атаками и значение урона. В текущем прототипе атака дополнительно демонстрируется сообщением в консоли и изменением цвета NPC.

## TeleportEnemyAI.cs
Скрипт отвечает за поведение второго типа противника - NPC с возможностью телепортации.
Основные состояния:
* Idle - ожидание;
* Patrol - патрулирование;
* Chase - преследование;
* Attack - атака;
* Search - поиск игрока;
* Teleport - выполнение телепортации.

В отличие от обычного противника, данный NPC использует обнаружение на 360° в небольшом радиусе. Проверка выполняется через заданный интервал времени. При обнаружении игрока противник начинает преследование.
Во время Chase проверяется возможность телепортации. Телепортация доступна после окончания cooldown и если игрок находится на достаточном расстоянии.
В состоянии Teleport NPC перемещается в сторону игрока на заданное расстояние. Для выбора конечной позиции используется NavMesh, поэтому телепортация выполняется только в доступную область. После телепортации NPC возвращается в состояние Chase.
Атака работает аналогично обычному противнику и имеет собственную дистанцию, cooldown и значение урона.

## NavMesh и NavMeshAgent
Для навигации NPC используется система Unity AI Navigation
NavMeshSurface создаёт навигационную область игровой сцены через "запекание" доступной области, а NavMeshAgent позволяет противникам самостоятельно строить путь до нужной позиции.
NavMesh используется для:
* более проработанной системы патрулирования;
* преследования игрока;
* перемещения к последней известной позиции;
* поиска допустимой позиции для телепортации и перемещения

Благодаря этому NPC могут обходить стены и другие препятствия, не двигаясь напрямую через них.

## Walls
Объекты стен используются как физические препятствия в игровой сцене.
Они имеют Collider и находятся на отдельном слое Walls. Этот слой используется системой обнаружения NPC для проверки видимости игрока через Physics.Raycast.
Таким образом, если между противником и игроком находится стена, NPC не может обнаружить игрока через неё.

## Общая схема работы
Оба противника используют один и тот же основной принцип FSM: в каждый момент NPC находится в одном состоянии, а переход в другое состояние происходит при выполнении определённого условия.
Обычный противник использует поле зрения 180°, а телепортирующийся противник - обнаружение на 360° и дополнительное состояние Teleport.

Основная логика системы находится в трёх скриптах:
PlayerMovement.cs
NormalEnemyAI.cs
TeleportEnemyAI.cs
Дополнительно для навигации используются NavMeshSurface и NavMeshAgent, а для проверки препятствий - система физических коллайдеров и Physics.Raycast
